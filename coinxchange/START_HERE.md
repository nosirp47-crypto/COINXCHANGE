# Start here — COINXCHANGE

## Fastest way to see it
On a computer, unzip the package and double-click `index.html`. It runs locally without installing software.

## What to click
1. Start on the Founder Edition welcome page. Explore Coins opens the existing Discovery area; Join Community opens the account demonstration.
2. Sign In, Create Account, and Forgot Password are visual demonstrations only. Their fields and actions are disabled; do not enter credentials. There is no authentication or password recovery service.
3. Use Overview to open the existing Home dashboard.
4. Discovery → choose a sample coin and click Show Discovery Guide. Photos preview locally (up to 10 MB) but are **not** analyzed.
5. Community → publish a demo post, like posts, and open a discussion to add local replies.
6. Market Exchange → filter the demo catalog, track coins, open a discovery guide, or save a reference coin to your vault.
7. My Collection → save a coin and add notes. Discovery and Market Exchange also provide shortcuts to your vault.
8. Launch Plan → view the roadmap. Read `MVP_BLUEPRINT.md` for technical details.

## If your phone will not open the HTML
Use a computer to unzip and open the file, or upload the single `index.html` file to a static website host. A static preview can be deployed using Netlify Drop or Cloudflare Pages, following the host's current instructions. Do not collect real users' personal data through this demo.

## What is and is not functional
Functional: navigation, responsive design, local image preview with a 10 MB limit, reference-based discovery guide, local posts/likes/replies, local collection, filtered watchlist, demo catalog category filters, and search across coin references and community discussions. Discussion replies are stored only in this browser and are not shared with other visitors.
Not functional yet: AI image recognition, live coin valuation, real user login or account recovery, shared social networking, secure payments, actual coin trading, production security, or public hosting.

## What you need to launch a real company
Choose and clear the brand name; buy a domain; set up a legal entity and developer accounts as appropriate; select a development team/stack; implement production backend, secure accounts, moderation and licensed market data; test with beta users; then add monetization and verified trading after compliance review.
