# Start here — COINXCHANGE

## Fastest way to see it
On a computer, unzip the package and double-click `index.html`. It runs locally without installing software.

## What to click
1. Overview → Discover a Coin.
2. Discovery → choose a sample coin and click Show Discovery Guide. A selected photo previews locally but is **not** analyzed.
3. Community → publish a demo post and like posts.
4. Market Exchange → add sample coins to a research watchlist.
5. My Collection → save a coin and add notes.
6. Launch Plan → view the roadmap. Read `MVP_BLUEPRINT.md` for technical details.

## If your phone will not open the HTML
Use a computer to unzip and open the file, or upload the single `index.html` file to a static website host. A static preview can be deployed using Netlify Drop or Cloudflare Pages, following the host's current instructions. Do not collect real users' personal data through this demo.

## What is and is not functional
Functional: navigation, responsive design, image preview, reference selection, local posts/likes, local collection, local watchlist, catalog search.
Not functional yet: AI image recognition, live coin valuation, user login, shared social networking, secure payments, actual coin trading, production security, or public hosting.

## What you need to launch a real company
Choose and clear the brand name; buy a domain; set up a legal entity and developer accounts as appropriate; select a development team/stack; implement production backend, secure accounts, moderation and licensed market data; test with beta users; then add monetization and verified trading after compliance review.
